# Telegram Task Manager

Telegram-бот для управления задачами.

## Возможности
- Добавление задач.
- Просмотр списка задач.
- Редактирование и удаление задач.
- Изменение статуса задач.
- Просмотр статистики.
- Постраничный вывод списка.

## Технологии
- Python 3.13
- aiogram 3.13.1
- SQLite
- python-dotenv
- pytest

## Установка и запуск
1. Установить зависимости: pip install -r requirements.txt
2. Создать файл настроек: cp .env.example .env
3. Указать токен бота в файле .env.
4. Запустить: python main.py

## Запуск тестов
python -m pytest -v
